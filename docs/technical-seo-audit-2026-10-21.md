# Технический SEO-аудит RPM Rent

**Дата:** 21.10.2026 · **Сайт:** `https://rpmrent.ru` · **Статус:** аудит завершён; подтверждённые безопасные правки выложены в production и проверены.

## 1. Резюме для владельца

Главный риск для заявок — не контент, а управляемость воронки и доменов:

1. `rpm-rent.ru` — не защитная регистрация: один счётчик Метрики принимает данные с обоих доменов, а в URL входа есть рекламные метки на `rpm-rent.ru`. Его нельзя переводить на 301 до выгрузки Директа и замены финальных URL кампаний.
2. В Яндекс Вебмастере зафиксированы 4 дубли Title, 5 дублей Description и рекомендация об отсутствии Description. В код внесены правки для подтверждённых дублей и для учёта успешной обычной заявки. Счётчик Метрики привязан к `rpmrent.ru` после аудита.
3. Google Search Console показывает 47 проиндексированных и 145 не проиндексированных URL. PageSpeed от 21.10 подтверждает mobile Core Web Vitals как «не пройдены»: field CLS 0,12 при LCP 2,3 с; laboratory performance 90. Главный резерв — 8,8 Миб изображений.
4. В проекте есть карта legacy 301, но внешние индексные следы всё ещё содержат старые карточки `/catalog/tproduct/*` с неактуальными условиями. Сначала нужно подтвердить фактическую production-конфигурацию и входящий трафик, затем отправить важные URL на переобход.

**Предварительная оценка:** 54/100. Это оценка состояния на основе доступных источников, а не показатель поисковой системы. Скорость, мобильная вёрстка, HTTP-заголовки и валидность schema требуют отдельных измерений.

## 5. Вопрос по `rpm-rent.ru` и варианты решения

Назначение домена не установлено. Нельзя доказать, что это зеркало, отдельный сайт, рекламный домен или защитная регистрация.

| Вариант владельца | Когда выбирать | Последствие |
|---|---|---|

## 7. Связка SEO, Метрики и Яндекс Директа

### SEO и Метрика

- Созданы цели типа «JavaScript-событие»: `booking_submit` (ID `673244095`) и `direct_lead_submit` (ID `673244296`).
- Не использовать `booking_submit_click` как целевую заявку: он срабатывает до ответа формы.
- Счётчик `111757927` уже привязан к Вебмастеру для `rpmrent.ru`; контролировать исчезновение рекомендации после обновления панели.
- Счётчик обслуживает оба домена, поэтому текущая Метрика не разделяет чисто SEO-данные `rpmrent.ru` и рекламный `rpm-rent.ru` без сегмента по hostname.
- Каждую неделю сверять: successful event → запись в админке → посещение `/spasibo`. Расхождение более 5% расследовать по `idempotencyKey`, ошибкам API и consent.

### Что запросить из Директа

За 90 дней: кампания, группа, запрос, поисковая фраза, расход, показы, клики, конверсии, стоимость конверсии, финальный URL, `utm_*`, `yclid` и hostname. Это нужно для трёх решений:

1. проверить, не используется ли `rpm-rent.ru`;
2. найти дорогие связки «запрос → посадочная» без `booking_submit` / `direct_lead_submit`;
3. использовать реальные поисковые фразы как кандидаты для карточек и максимум 1–2 новых посадочных.

Ставки, бюджеты, объявления и аудитории не менялись.
