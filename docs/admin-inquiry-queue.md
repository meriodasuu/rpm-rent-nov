# Очередь обращений

На `/admin/bookings` бронирования и короткие лиды Яндекс.Директа отображаются вместе, по времени поступления от новых к старым. Поиск по имени, телефону и автомобилю и счётчики вкладок учитывают выбранный тип обращения. Телефон можно вводить с пробелами, скобками и дефисами.

«Сегодня» означает обращения, поступившие сегодня по московскому времени. «В работе» включает новые и обрабатываемые обращения. Выполненные лиды доступны во вкладке «Завершены / обработаны», отклонённые — во вкладке «Отказ». Если результат пуст, карточка клиента справа тоже очищается.

Для лида доступны статусы NEW (Новый), IN_PROGRESS (В работе), COMPLETED (Обработан), DECLINED (Отказ). Менеджер может исправить статус или вернуть лид в работу. Изменение сохраняется через защищённое серверное действие и не создаёт бронирование, не блокирует автомобиль и не отправляет уведомление. Существующее строковое поле Lead.status используется без миграции базы.

В карточках бронирований и лидов есть поле «Комментарий менеджера» (до 1000 символов). Кнопка «Сохранить комментарий» сохраняет заметку; пустое поле очищает её. Комментарий клиента хранится отдельно. Бот показывает заметки в полной карточке и краткий текст в списках; после изменения на сайте нужно заново открыть карточку или обновить список в боте. Ранее отправленные уведомления автоматически не редактируются. Поля добавляются миграцией `20260914170000_inquiry_comments` без изменения существующих данных.
