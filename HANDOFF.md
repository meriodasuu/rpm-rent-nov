## Что это за проект

Многостраничный сайт аренды премиальных автомобилей в Санкт-Петербурге. Основной сценарий: главная → каталог → карточка автомобиля → бронирование → заявка менеджеру. Есть защищённая админ-панель, управление автомобилями и контентом, Telegram-уведомления и мониторинг объявлений маркетплейсов.

### Стек

- Next.js 16 App Router, React 19, TypeScript strict;
- Prisma 7 и PostgreSQL; локальный dev fallback хранит данные в `.data/db.json`;
- Vitest, ESLint, pnpm.

## Быстрый старт

Требуются Node.js 22+ и pnpm 11+. Создай `.env.local` на основе `.env.example`, установи зависимости и запусти:

```bash
pnpm install
pnpm prisma:generate
pnpm seed
pnpm dev
```

Локальный сайт: `http://localhost:3000`; админка: `http://localhost:3000/admin`. Локальные реквизиты, если они настроены в `.env.local`, предназначены только для разработки. Не используй их в production.

Полезные команды:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## Ориентиры в репозитории

- `src/app/` — страницы, API routes и админка;
- `src/components/` — интерфейсные компоненты;
- `src/lib/` — бизнес-логика, интеграции, хранилища;
- `src/data/seed.ts` — локальные демонстрационные данные;
- `prisma/schema.prisma`, `prisma/migrations/` — схема и миграции БД;
- `deploy/`, `compose.production.yml`, `Dockerfile` — production-развёртывание;
- `docs/` — аудит, SEO, интеграции и эксплуатационные заметки.

README содержит подробные инструкции запуска, конфигурации, БД и функций. Файл `docs/deployment-access.md` содержит приватные эксплуатационные сведения; читай его только при наличии полномочий на доступ к серверу. Не копируй из него ключи, пароли или содержимое окружения в коммиты и ответы.

## Важные ограничения

- Не добавляй `.env.local`, `.env.production`, `.data/`, пароли, токены, приватные ключи и дампы базы в Git.
- В `.env.example` должны оставаться только пустые шаблонные значения, без рабочих ID и доступов.
- Данные seed могут быть демонстрационными. Не публикуй цены, условия аренды, контакты, отзывы и юридические сведения без подтверждения владельца.
- Не деплой и не меняй production-инфраструктуру без отдельной явной задачи.
- Перед изменениями в Next.js сверяйся с локальной документацией установленной версии в `node_modules/next/dist/docs/`.
- Перед миграциями базы данных сначала изучи текущую схему, историю миграций и целевое окружение.
